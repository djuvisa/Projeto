QUAIS SÃO AS MATERIAS?

DESIGN DE INTERFACE

Na matéria de Design de Interface, você aprende a projetar a ponte visual e interativa entre o usuário e um produto digital. O objetivo é tornar essa navegação intuitiva, esteticamente agradável e acessível.

PROGRAMAÇÃO WEB

A programação web ensina a criar, estruturar e gerenciar sites e sistemas que funcionam diretamente nos navegadores de internet.

BANCO DE DADOS

A disciplina de Banco de Dados ensina os fundamentos essenciais para armazenar, organizar, manipular e recuperar informações em sistemas computacionais. Ela aborda desde o planejamento lógico e visual das estruturas de dados até a implementação e gerenciamento de bancos de dados relacionais e não-relacionais usando a linguagem SQL
